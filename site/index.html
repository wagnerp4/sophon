sophon

A local-first terminal harness. One process for dashboard, editor, and model chat. The rest of the map is still in flux. This page stays thin on purpose.

Install

Entry point is sophon-cli. Until a PyPI release exists, clone the repo and use uv. 

git clone https://github.com/wagnerp4/sophon.git
cd sophon
uv sync --extra tui --extra finetune
cp .env.example .env
.venv/bin/sophon-cli chat --no-spawn-window

From a checkout without a venv path prefix, the same command is sophon-cli after uv sync.

Platforms

  • Linux (Arch / Omarchy, single tree). One checkout. Do not set SOPHON_WINDOWS_ROOT. Run in the current TTY with --no-spawn-window, or a REPL: sophon-cli chat --interface repl.
  • Windows (two trees). Edit in WSL, deploy a GPU copy with sophon-cli deploy-windows. If Windows Terminal reports 0x8007010b, the deploy folder is gone. Recreate it from WSL. Details: README.
  • Headless. sophon-cli chat --interface repl does not need a desktop emulator.
